# Exp

Эксперимент: вырастить **своего** маленького ученика, а не брать готовую большую модель.

Сначала появляется ребёнок — формула со случайными весами. Он ещё ничего не знает. Потом его учат, как человека: сначала русскому, потом английскому, потом Python.

## Кто этот ребёнок

Это крошечный трансформер. Он смотрит на **байты UTF-8**, поэтому с рождения видит и кириллицу, и латиницу, и знаки кода. Знаний в нём нет: ручки (веса) в начале случайные.

Размер — около 840 тысяч параметров, несколько мегабайт, не терабайты.

Тело и тетрадь разделены:

- веса модели — то, чему учим сейчас;
- `notes/TETRAD.md` — будущие сжатые уроки, пока пустые.

## Школа

1. `russian_yasli` — простые русские фразы. **Сейчас учим это.**
2. `english_placeholder` — английский, позже, не забывая русский.
3. `python_placeholder` — код, ещё позже.

## Запуск

```bash
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -t .
python3 -m child.train --stage russian_yasli --steps 800
python3 -m child.sample --prompt "Мама "
```

После урока чекпоинт лежит в `checkpoints/child_russian_yasli.pt`.

До школы ребёнок выдаёт шум. После короткого урока на простых фразах начинает повторять знакомые куски речи. Это не ChatGPT. Это лепет.
