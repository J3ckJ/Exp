# Exp

Эксперимент: вырастить **своего** маленького ученика, а не брать готовую большую модель.

Сначала появляется ребёнок — формула со случайными весами. Он ещё ничего не знает. Потом его учат, как человека: сначала русскому, потом английскому, потом Python.

## Кто этот ребёнок

Это крошечный трансформер. Он смотрит на **байты UTF-8**, поэтому с рождения видит и кириллицу, и латиницу, и знаки кода. Знаний в нём нет: ручки (веса) в начале случайные.

Размер сейчас — около **8.1 млн** параметров (возраст teen: окно 512 байт, 10 слоёв). Старое тело schoolkid (~6.4 млн) лежит рядом, если нужно откатиться.

Тело и тетрадь разделены:

- веса модели — привычка говорить;
- `notes/BRAIN.md` — маленький мозг: короткие фразы, не терабайты;
- `notes/PLAN.md` — последний урок руками: что искал, что понял, какая дыра;
- `notes/TETRAD.md` — дневник ночной школы рта.

## Конечный механизм

Две петли. Они не смешиваются.

**Руки (работа).** Команда `изучи …` или `изучи дальше`.

1. Разобрать задание (что это / как устроено).
2. Найти страницы: поиск, вики-extract, официальные доки если продукт знаком.
3. Взять одну страницу по смыслу задания. Не disambiguation, не скин, не соседняя тема.
4. Отжать 2–4 факта в `notes/BRAIN.md`.
5. Решить, какой кусок устройства ещё дыра — не побочное применение.
6. Идти в дыру, не перечитывая ту же статью.
7. Остановиться, когда в тетради есть механизм, или кончились страницы.
8. Записать `notes/PLAN.md`. `изучи дальше` читает дыру из плана.

Рот не трогаем. Страницы Git, TLS, HTTP, Битрикса в веса рта не идут.

**Рот (речь).** Команда `поучи …` и `python3 -m child.night`. Поёт тетрадь и учебник, чтобы «Привет» не стал print. Интернет для рта — язык и короткие песни, не внутренности продуктов.

**Один взгляд.** `что такое …` / `узнай …` — одна страница, не миссия.

Цель: помощник по работе. Учёба рта — побочный продукт, не путь к ChatGPT.

## Возраст, не чудо

Сейчас это **малыш**. Он учит русский. Английский ещё в коридоре, не в классе.

Разговаривать — да, надо. Сначала как с маленьким: коротко спросил — коротко ответил. Для этого есть `python3 -m child.chat`.

Он уже не только лепечет. Как у Джарвиса, руки отдельно от голоса: время и дата в Москве, запомнить в тетрадь, ответить из тетради, посмотреть в Википедии, посчитать, пойти учиться до утра, **сам найти тему и выбрать следующий урок**. Голос — ~8.1 млн параметров. Думать «чему учиться дальше» рот не умеет: это руки и `notes/PLAN.md`. Это не ChatGPT и не будет им за одну ночь. Это помощник, который сам учится и сам делает маленькие дела.

Говорить **как со мной** — другой возраст. У меня огромное тело, длинная память, море книг. У него рот на байты UTF-8 и около 8 млн ручек. Если растить его честно, он станет собеседником-ребёнком, потом подростком (больше слоёв, длиннее память, сам читает ночами). Взрослый разговор «как здесь» без большого тела не получится — и не надо притворяться, что получится.

Порядок дальше:

1. Русский, английский, Python как байты — **уже умеет**, пока не срывается.
2. Джарвис-руки на том же теле: время, тетрадь, вики, счёт, **простой Python**, GitHub.
3. Самоучка таскает короткие тексты (Википедия, raw GitHub), потом повторяет песни.
4. Подросток `teen` (~8.1 млн, окно 512 байт, 10 слоёв): **уже вырос копированием** schoolkid, не случайным телом. Дальше — больше историй и, когда появится GPU, следующий скачок ширины.
5. `schoolkid` (~6.4 млн) остаётся на лестнице ниже. Старые тела лежат в `checkpoints/child_preschooler.pt` и `child_schoolkid.pt`.

Возраст `preschooler`: рот 192 байта, 6 слоёв, ширина 192, около 2.8 млн параметров. Всё ещё ребёнок. Не ChatGPT.

## Школа

1. `russian_yasli` — первый день. Все сочетания подряд. Ребёнок начал лепетать, но путает «читает яблоко».
2. `russian_core` / `russian_school` / `russian_recitation` — настоящий учебный день: только живые пары, диалоги, короткие истории, повтор золотых фраз.
3. `russian_talk` — очередь говорить: «Ты: … / Я: …».
4. `russian_power` — плотный день после скачка роста: перефразы, «я не знаю», старый мир.
4a. `russian_stories` — длинные сцены под рот 512 байт: кто что делает, потом чай, плюс «я не знаю».
5. `english_school` — английский, русский не выключая.
6. `python_school` — крошечный Python как язык байтов, плюс память RU/EN.
7. `world_school` — короткий мир: Москва, Земля, Солнце, руки помощника.
8. `recite_all` — спеть все песни, чтобы Привет не стал print.
9. `python3 -m child.night` — учиться самому до 07:20 по Москве.

Учитель не рождает ребёнка заново. `python3 -m child.train` продолжает с чекпоинта.

## Запуск

```bash
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -t .
python3 -m child.train
python3 -m child.exam
python3 -m child.learn --wish "читать самому" --from data/readers/sam_chitayu.txt
python3 -m child.sample --prompt "Я "
python3 -m child.train --age preschooler --stage russian_power --steps 3500 --lr 3e-4
python3 -m child.train --stage english_school --steps 2500 --lr 1.2e-4
python3 -m child.train --stage python_school --steps 2500 --lr 1.0e-4
python3 -m child.learn --wish "поучи python в интернете" --web --steps 1000
python3 -m child.chat --say "поучи english"
python3 -m child.chat --say "который час"
python3 -m child.chat --say "какое сегодня число"
python3 -m child.chat --say "сколько будет 12*8"
python3 -m child.chat --say "что такое Москва"
python3 -m child.chat --say "что ты знаешь про Землю"
python3 -m child.chat --say "запомни Хозяина зовут Евгений"
python3 -m child.chat --say "выполни print(\"hello\")"
python3 -m child.chat --say "прочитай тетрадь"
python3 -m child.chat --say "поучи github"
python3 -m child.chat --say "изучи как делается ЦРМ в битриксе"
python3 -m child.research --wish "изучи как устроен TLS"
python3 -m child.research --expand
python3 -m child.chat --say "как ты учишься"
python3 -m child.chat --say "вырасти"
python3 -m child.grow
python3 -m child.train --stage russian_stories --steps 2000 --lr 1.2e-4 --batch-size 16
python3 -m child.learn --wish "поучи python в интернете" --web --allow-grow
python3 -m child.night
python3 -m child.morning
```

Один урок, если нужно: `python3 -m child.train --stage russian_core --steps 800 --resume checkpoints/child_latest.pt`.

После школы чекпоинт лежит в `checkpoints/child_latest.pt`.

До школы ребёнок выдаёт шум. После яслей — лепет. После учебного дня должен устойчивее повторять живые фразы. Это не ChatGPT. Это ученик.
